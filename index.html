Partie 1 : Les formulaires HTML

Structure de base

Un formulaire s’écrit avec la balise <form>. L’attribut name l’identifie.

<form name="f">
  ...champs...
</form>

Champs courants

ÉlémentRôle
type="text"texte court
<textarea>texte long
type="submit"envoyer
type="reset"réinitialiser

Attributs importants

required : champ obligatoire size : largeur en caractères autofocus : curseur au chargement placeholder : texte d’aide

label : relie un libellé à un champ grâce à for = id (le clic sur le texte active le champ).

<label for="email">E-mail :</label>
<input type="email" id="email" required>

Organiser : fieldset, legend, hr

fieldset = cadre qui regroupe, legend = son titre, hr = ligne de séparation. Voici le rendu :

Cases à cocher

Plusieurs choix possibles.

<input type="checkbox" id="html">

Boutons radio

Un seul choix : même name pour tout le groupe.

<input type="radio" name="niveau">

Liste déroulante

Beaucoup d’options dans peu de place.

<select name="pays">
 <option>France</option>
</select>

Partie 2 : Le CSS

Lier le CSS au HTML

Fichier externe .css, lien dans le <head> : code séparé, réutilisable, plus rapide.

<link rel="stylesheet" href="styles.css">

Syntaxe

selecteur {
  propriete: valeur;
}
